# Практическая работа: маршрутизация и навигация Next.js

## Отчёт по практической работе

**Тема:** Маршрутизация и навигация в Next.js. Layouts и Templates.

**Репозиторий:** [HeexMex/nextjs-lab](https://github.com/HeexMex/nextjs-lab)

### Выполненные задания

1. Создан проект Next.js с App Router и TypeScript.
2. В `app/layout.tsx` создан корневой layout с `html`, `body` и `children`.
3. Добавлена общая навигация через компонент `Link`.
4. Создан статический маршрут `/about`.
5. Создан список постов `/blog` с интерфейсом `Post`.
6. Создан динамический маршрут `/blog/[id]` с типизацией `params: Promise<{ id: string }>`.
7. Настроены переходы из списка постов к страницам постов.
8. Создан вложенный динамический маршрут `/blog/[id]/comments/[commentId]`.
9. Для блога реализован `layout.tsx` с состоянием счётчика.
10. Для блога реализован `template.tsx` с отдельным счётчиком и логированием в консоль браузера.
11. Можно проверить, что layout сохраняет состояние, а template его сбрасывает при переходе между страницами блога.
12. Реализован `NavBar` с `usePathname` и выделением активной ссылки.
13. `NavBar` подключён в корневом layout.
14. Добавлена кнопка навигации с `useRouter().push('/about')`.
15. Дополнительно реализован раздел «Курсы» с `/courses`, собственным layout и динамическим `/courses/[slug]`.

### Результат

Создан многостраничный сайт с файловой маршрутизацией, клиентскими ссылками, вложенными динамическими маршрутами и наглядной демонстрацией разницы между layout и template.

## Как запустить

Требуется Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте **http://localhost:3000**. Проверка TypeScript: `npm run lint`. Сборка: `npm run build`.

## Что проверить

| Адрес | Что демонстрирует |
| --- | --- |
| `/` | Главная страница с навигацией |
| `/about` | Статическая страница |
| `/blog` | Список постов через `Post[]` и `Link` |
| `/blog/1` | Динамический сегмент `[id]` и асинхронный `params` |
| `/blog/1/comments/5` | Два динамических сегмента `[id]` и `[commentId]` |
| `/courses` | Раздел «Курсы» с вложенным layout |
| `/courses/nextjs` | Динамическая страница курса `[slug]` |

**Активная ссылка:** во время переходов смотрите на цвет пункта в меню. Кнопка «Перейти к О нас» показывает `useRouter().push()`.

**Layout / Template:** перейдите в блог, увеличьте оба счётчика кнопками, затем откройте пост и вернитесь. Счётчик **Layout** сохраняется, а счётчик **Template** сбрасывается. В консоли браузера при каждом переходе внутри блога появляется `BlogTemplate смонтирован заново` (при разработке React Strict Mode может повторно запускать эффекты).

## Структура

```text
app/
├── layout.tsx                    # Корневой layout и общая навигация
├── page.tsx                      # /
├── about/page.tsx                # /about
├── components/NavBar.tsx         # Link, usePathname, useRouter
├── blog/
│   ├── layout.tsx                # Состояние сохраняется
│   ├── template.tsx              # Состояние сбрасывается
│   ├── page.tsx                  # /blog
│   └── [id]/
│       ├── page.tsx              # /blog/:id
│       └── comments/[commentId]/page.tsx  # /blog/:id/comments/:commentId
└── courses/
    ├── layout.tsx
    ├── page.tsx                  # /courses
    └── [slug]/page.tsx           # /courses/:slug
```

## Примеры проверки

- `http://localhost:3000/about`
- `http://localhost:3000/blog/1`
- `http://localhost:3000/blog/1/comments/5`
- `http://localhost:3000/courses/nextjs`

При переходах внутри блога счётчик Layout сохраняет значение, а Template обнуляется. При выборе активного раздела подсвечивается соответствующая ссылка.
